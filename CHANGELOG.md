# Changelog / Histórico de alterações

## 0.1.0 — 2026-11-15

### English

- First build kit for Cadillacs and Dinosaurs, World 930201.
- Automated local ROM verification, code translation and Windows x64 compilation.
- Dependency downloads pinned by version and SHA-256 hash.
- Expanded 16:9 scenery, with camera, enemy visibility and movement adjustments.
- Widescreen adaptations for the opening, transitions and special screens.
- English pause menu with Infinite Ammo and Infinite Health.
- Local Windows and Bazzite/Proton packages.
- Source auditing and automated checks that do not require a ROM.

Only kit source files are distributed. The ROM, translated game program,
game executable, artwork and audio are excluded.

### Português (Brasil)

- Primeira versão do kit para Cadillacs and Dinosaurs, World 930201.
- Verificação local da ROM, tradução do código e compilação para Windows x64 automatizadas.
- Download de dependências com versões e hashes SHA-256 fixados.
- Cenário ampliado para 16:9, com ajustes de câmera, exibição dos inimigos e movimento.
- Adaptações de widescreen na abertura, nas transições e nas telas especiais.
- Menu de pausa em inglês com Infinite Ammo e Infinite Health.
- Geração local de pacotes para Windows e Bazzite/Proton.
- Auditoria do código-fonte e verificações automatizadas que não exigem uma ROM.

A distribuição contém apenas o código-fonte do kit. A ROM, o programa traduzido
do jogo, o executável, as imagens e o áudio não estão incluídos.
