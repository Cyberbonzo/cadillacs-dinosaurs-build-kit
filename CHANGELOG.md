# Changelog

## 0.1.0 — 2026-11-15

- Initial source-only public build kit for the World 930201 ROM set.
- Pinned dependency downloads with SHA-256 verification.
- Local ROM member verification, translation, native compilation and smoke test.
- Expanded 16:9 scenery, camera boundaries, enemy visibility and player movement.
- Adapted opening, transitions and special-screen layouts.
- Start pause menu with Infinite Ammo and Infinite Health in English.
- Local Windows and Bazzite/Proton package generation.
- Public-file allowlist, history audit and ROM-free CI tests.

No ROM, game-derived generated code, game executable or artwork is distributed.
