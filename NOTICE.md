# Notices / Avisos

## English

Cadillacs and Dinosaurs Build Kit is an unofficial project for the World 930201
arcade ROM set. It is not affiliated with or endorsed by Capcom or the game's
other rights holders. The project grants no rights to the original game, its
ROM, artwork, audio, names or logos.

The source patch modifies [CPS2Recomp v1.5.0](https://github.com/tmcleroy/cps2recomp)
by Tommy McLeroy and contributors. The kit software and source modifications are
licensed under GPL-3.0-only. Existing copyright notices are retained.
The license text is provided in [LICENSE](LICENSE).

Build dependencies are downloaded separately from their official projects and
retain their own licenses. Consult the notices included with CPS2Recomp, SDL,
zlib, llvm-mingw, CMake and Ninja. Their binaries are not included in this repository.

The public patch contains implementation changes and numeric compatibility
metadata. It does not include the translated 68000/Z80 game program or embedded
game assets. A compatible ROM must be provided separately; no ROM download is
offered. Local build outputs contain the supplied ROM and a game-derived
executable and must not be uploaded to this repository or its releases.
